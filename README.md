# Contact Form/List

This component allows users to submit and view contact information in a clean and organized format. The **Contact Form** collects essential details such as name, email, phone number, and a message. Submitted entries are stored and displayed in the **Contact List**, making it easy to manage and review communications.

## Features

- Easy-to-use form for collecting contact info
- Validations for email and phone formats
- Dynamic list display with edit/delete functionality
- Ideal for portfolio sites, small business pages, or internal tools
